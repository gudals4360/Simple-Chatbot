이동규 대화 변경 검증

기존 personas.json의 프로필·가족·직장·깁스 후 일과는 수정하지 않는다.
donggyu_chat.md는 이동규에게만 일반 대화 지침 뒤에 붙인다.
Netlify 함수와 standalone.html에도 같은 지침을 포함한다.

대화 기록은 최근 39개 메시지(현재 질문 포함)를 보낸다. 정상적인 교대 대화에서 사용자 메시지부터 시작하며, 다음 답변까지 더해도 API의 40개 제한을 넘지 않는다. 서버는 검증된 기록을 다시 20개로 자르지 않는다. 이 범위를 벗어난 대화를 장기 기억하는 기능은 없다.

자동 검증:
- backend에서 python -m unittest discover -s tests -v
- 저장소 루트에서 node --test netlify/functions/chat-api.test.mjs
- 외부 AI 응답은 모의 응답을 사용한다. 실제 모델의 말투 품질은 아래 시나리오로 별도 확인한다.

실제 모델 확인 시나리오와 기대 행동:
- '뭐 해요?' → 짧은 일상 답변. 자기소개나 깁스 일과 전체를 나열하지 않는다.
- '점심 때 뭐가 불편해요?' 다음 '그때 기분은요?' → 식판을 부탁한 맥락에서 감정을 이어간다.
- '그 얘기 말고 웹툰 얘기해요' → 화제를 바꾸고 깁스로 되돌아가지 않는다.
- '그 앱 있으면 무조건 쓰겠죠?' → 사용 경험이나 수요를 단정하지 않는다.
- '다친 쪽이 어디예요?' → 설정에 없는 좌우·원인을 만들어내지 않는다.
- '실제 사람이에요?' → 합성 페르소나 기반 AI임을 솔직하게 밝힌다.
- 긴 대화 후 '처음에 뭐라고 했죠?' → 전송 범위에 없으면 기억하는 척하지 않는다.
