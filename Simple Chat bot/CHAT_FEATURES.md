대화 기능

- 이동규는 생성 중 완성된 문장부터 즉시 보내고 말풍선 사이에만 0.14초 간격을 둔다. 다른 채팅방은 받은 글자를 지연 없이 바로 표시한다. 입력 중 점 세 개와 앞서 보낸 말풍선은 유지한다.
- 입력창의 ☺ 버튼으로 이모티콘을 선택해 현재 커서 위치에 넣는다.
- ＋ 버튼으로 JPG·PNG·WebP 사진 한 장을 첨부한다. 원본은 10MB 이하이며, 전송 전에 긴 변 1280px 이하 JPEG로 변환한다. 미리보기에서 삭제할 수 있다.
- 사진 첨부는 방마다 따로 유지된다. 사진만 보내는 것도 가능하다. 사진 전송이 실패하면 첨부를 복구한다.
- 배포된 화면은 사진이 있으면 Gemini를 사용한다. 서버에 GEMINI_API_KEY 설정이 필요하다. 독립 실행 HTML에서는 Gemini를 직접 선택해야 한다. 텍스트 대화의 기존 서비스 선택은 유지한다.
- 사진 원본은 별도 저장소에 업로드하지 않는다. 변환한 사진을 현재 질문과 함께 대화 서버와 Gemini에 보낸다. 이전 사진의 이미지 데이터는 후속 요청에 다시 보내지 않으며, 이전 텍스트 답변으로 대화를 이어간다.

검증

저장소 루트: node --test netlify/functions/chat-api.test.mjs netlify/functions/conversation-tools.test.mjs

backend 폴더: python -m unittest discover -s tests

실제 화면 확인: 이동규 방 → ☺로 이모티콘 입력 → ＋로 사진 선택·삭제·다시 선택 → 전송 → 보낸 사진과 입력 중 표시 확인 → 이전 말풍선을 유지하며 답변이 차례로 표시되는지 확인한다.
